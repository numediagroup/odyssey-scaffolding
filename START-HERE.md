# START HERE: odyssey-scaffolding

Read this first, then CURRENT-WORK.md. Both are kept up to date by the Nu Media setup; nobody has to write them by hand.

## What this is
- **Client:** Not recorded
- **What it is:** Odyssey Scaffolding — domestic & commercial scaffolding homepage (Greater London & Surrey)
- **Stage:** live (of the five website stages: sales, design, build, QC, live; from a client domain is built from this repository)
- **Tier:** Not recorded

## Where it is hosted
- **Host:** netlify, site `odyssey-scaffolding`
- **Client's own domain:** odysseyscaffolding.co.uk
- **A push or merge to `main` publishes the live site (odysseyscaffolding.co.uk).** It needs the director's word in that request, every time. Work on a work branch.

## How to preview it
Open this repository in the Claude app and say "preview this site". Claude serves the site folder on this Mac. That uses no hosting credits and publishes nothing.

## Where things are
- `CURRENT-WORK.md`: which branch holds the newest work, who has it, what is approved, what is open, what not to touch.
- `NOTES.md`: the decisions log, newest first.
- `.nu-media/`: the repository's records (control record, receipts).

## Rules of this repository
- **Branches:** `work/<first name>/<what it is>-<date>`. One job, one branch.
- **Work comes home:** a finished, approved round ends on `main`, or as a pull request that names its owner. `main` is never left weeks behind.
- **Nothing is deleted or closed** without the director's word.
- You do not need special words. Say what you want; Claude reads these files first and starts from the newest work.
